# nom-prenom-r308 : R3.08 POO Python

Un dossier par TP. Python 3.10 ou plus. Chaque script se lance depuis son dossier
(`cd tp1`, `cd tp2` ou `cd tp3`).

## TP1 : dictionnaire d'étudiants, Devine le nombre, Pendu

- `python etudiants.py` : partie A (jeu d'essai)
- `python devine.py` : partie B
- `python mots.py` : partie C
- `python pendu.py` : partie D et bonus (scores.txt, mode voisin)

## TP2 : Morpion

- `python grille.py` : partie A (jeu d'essai de la classe Grille)
- `python joueurs.py` : partie B
- `python ia_malin.py` : bonus (IA qui gagne ou bloque)
- `python morpion.py` : partie C (jeu complet, scores, 2 humains, IA contre IA)

Coordonnées : `ligne colonne`, de 0 à 2.

## TP3 : gestion d'une bibliothèque

- `python livre.py` : partie A (jeu d'essai de Livre)
- `python utilisateur.py` : partie A (Utilisateur)
- `python bibliotheque.py` : partie B (jeu d'essai, cas piégés, stats)
- `python persistance.py` : partie C (sauvegarde et rechargement CSV)
- `python main.py` : partie D (menu complet, données dans `livres.csv` et `utilisateurs.csv`)
